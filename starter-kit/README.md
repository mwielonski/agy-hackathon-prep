# Hackathon Starter Kit

Welcome to the **AGY Hackathon Starter Kit** directory!

This directory contains pre-configured project templates and code snippets to give your hackathon team a 10-minute head start.

## 📁 Directory Overview

- **`data/sample_bq_queries.sql`**: Sample BigQuery SQL templates for schema discovery and data analytics.
- **`agents/adk_agent_template/`**: Skeleton directory for scaffolding your Google ADK agent.

## 🚀 How to Use with AGY

1. Open this workspace in AGY (or open a terminal in this directory).
2. Tell AGY: *"AGY, inspect `starter-kit/data/sample_bq_queries.sql` and adapt it to query our target BigQuery dataset."*
3. Or scaffold a new agent: *"AGY, use `google-agents-cli-scaffold` to create a new ADK agent inside `starter-kit/agents/`."*
